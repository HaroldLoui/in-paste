# in-paste → gpui-kit Spike（阶段 0）

独立验收工程，**不改动**根目录 egui 版代码。

## 运行

```powershell
cd spike
cargo run
```

首次编译较久（GPUI 依赖树）。建议用 release 或按 Cargo.toml 里的 profile 覆盖。

## 验收清单

| # | 项 | 操作 | 通过标准 | 状态 |
|---|---|---|---|---|
| 1 | 无边框+透明+圆角，无标题残影 | 反复点「置顶」、Alt-Tab 切走切回 | 抓帧无 `in-paste` 标题残影 | ✅ |

| 6 | 样式对照 | 白底/黑底对照 `ui.png` | 卡片干净、留白全透（无阴影/无白边） | ✅ |

### 过程记录

- 标题残影：GPUI 原生 Win32 窗口 + `harden()` 后未复现。
- 白边：两层问题——① gpui-component RootPlugin 给根表面刷了不透明主题底色（已置透明）；② 卡片 `BoxShadow` 投影在白底显灰（按需求去掉，只留卡片本体）。

## 与旧版差异（预期内）

- 无全局热键 / 托盘 / 真实剪贴板（阶段 2+）
- 行内按钮为占位 glyph，阶段 2 换矢量图标
- 无阴影/描边（按 2026-11-11 反馈去掉；如需恢复见 `ui.rs` git 历史）
- 布局用 flex + px 硬摆，未做 rem 缩放
- 置顶/隐藏按钮在工具栏，仅为验收入口

## 失败即回炉的项

- 项 1 残影仍在 → GPUI 窗口层同样有 DWM 问题，评估自建 Win32 窗口
- 项 3 IME 不可用 → 搜索核心交互不成立
- 项 5 取不到 hwnd → cloak/置顶/穿透全部做不了

**结论：7/7 通过，可以进入阶段 1 正式重写。**
